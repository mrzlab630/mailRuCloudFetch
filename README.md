# Mail Cloud • WebDAV TUI

Версия: **1.0.0**

Интерактивный загрузчик файлов и папок из Cloud.Mail.ru по WebDAV для Linux/macOS.

Запуск из интерактивного Linux-терминала:

```bash
./run.sh
```

Python 3.10+; Textual 7 и Requests. Зависимости изолированы в `.venv`. Если окружение отсутствует, launcher создаёт его и устанавливает `requirements.txt`.

Логин и WebDAV ключ можно ввести прямо в интерфейсе. Все поля скрыты. Введите мастер-пароль (минимум 12 символов) и нажмите «Сохранить зашифрованно». Данные атомарно записываются в `~/.config/cloudmailru/credentials.enc`: AES-256-GCM, ключ выводится из мастер-пароля через scrypt (N=32768, r=8, p=1), соль и nonce случайны при каждом сохранении. Файл имеет режим `0600`, каталог — `0700`. Мастер-пароль не записывается и после операции очищается из поля.

При следующем запуске введите мастер-пароль и нажмите «Расшифровать». Credentials доступны в памяти процесса; зашифрованный файл имеет приоритет над `.env` и переменными окружения. Неверный пароль и повреждение шифротекста отклоняются. Без зашифрованного файла сохраняется совместимость с `.env` и переменными окружения. Во время скачивания смена аккаунта запрещена. Облако используется только для чтения.

Старый `~/.config/cloudmailru/credentials.env` больше не читается и автоматически не удаляется. Для переноса заполните логин/ключ и сохраните зашифрованно, затем проверьте разблокировку. Старый файл и `.env` остаются незашифрованными копиями: удалите их самостоятельно, если они больше не нужны. Забытый мастер-пароль восстановить нельзя; можно заново ввести credentials и сохранить с новым паролем.

Управление:

| Действие | Клавиша |
|---|---|
| Перемещение | Стрелки |
| Открыть папку | Enter |
| Родительская папка | b |
| Выбрать файл/папку | Space |
| Обновить каталог / повторить соединение | r |
| Скачать выбранное | d или кнопка |
| Пауза / продолжить | p |
| Остановить с сохранением частичных файлов | x |
| Открыть путь в веб-интерфейсе | o |
| Выйти с остановкой потоков | q |

В верхней строке формы можно изменить логин, WebDAV ключ и мастер-пароль. После сохранения или разблокировки каталог загружается заново. Если credentials отсутствуют, приложение всё равно запускается и показывает эту форму.

Tab переключает фокус между таблицей, папкой назначения, числом потоков (1–16) и кнопкой. Выбор сохраняется при переходах между каталогами. Выбранные папки скачиваются рекурсивно с сохранением структуры; вложенные повторные выборы исключаются. Общий размер вычисляется после сканирования, до загрузки. Скорость отражает реально полученные байты за последний интервал, отдельно учитывая ранее скачанные данные. Неизвестные размеры отмечаются явно.

Для возобновления после выхода или аварийного завершения снова выберите те же объекты и ту же папку назначения. Рядом сохраняются `.part` и `.part.json` с версией исходного файла. Возобновление использует `Range`/`If-Range`; если сервер игнорирует Range или нет валидатора версии, скачивание начинается заново. Готовые файлы не перезаписываются; конфликты показываются как ошибки. Пауза/остановка действует на границе блока; зависший сетевой запрос ограничен тайм-аутом 30 секунд. Не запускайте одновременно несколько копий в одну папку назначения.

Дата создания показывается только из WebDAV `creationdate` и не интерпретируется как доказанная дата загрузки в облако. Дата изменения — `getlastmodified`; MIME тип — `getcontenttype` (или расширение). WebDAV не предоставляет подтверждённых публичных ссылок: `o` открывает частный путь в веб-интерфейсе Mail, где требуется авторизация; разрешение ссылки для конкретного файла зависит от интерфейса Mail.

## Официальная документация и проверка

[Официальная справка Mail: доступ по WebDAV](https://help.mail.ru/cloud/desktop/webdav/) подтверждает адрес `https://webdav.cloud.mail.ru/` и пароль внешнего приложения вместо основного пароля. Детальную документацию API Mail не публикует на этой странице; методы и свойства реализованы по [RFC 4918 (WebDAV)](https://www.rfc-editor.org/rfc/rfc4918) и [RFC 9110 (HTTP Range)](https://www.rfc-editor.org/rfc/rfc9110).

```bash
./run.sh --check
```

Если существует зашифрованное хранилище, используйте TUI для разблокировки и проверки подключения; `--check` мастер-пароль не запрашивает.

При проверке 14.10.2026 авторизованный PROPFIND возвращал HTTP 500, без авторизации сервер возвращал HTTP 401 Basic realm=Dav. Поэтому реальный листинг/скачивание этого аккаунта пока не подтверждены. Это не доказывает ни неверный ключ, ни проблему тарифа. Не меняйте credentials без самостоятельной проверки.
