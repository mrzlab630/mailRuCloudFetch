# Mail Cloud • WebDAV TUI

Версия: **1.7.0**

Интерактивный загрузчик файлов и папок из Cloud.Mail.ru по WebDAV для Python 3.10+.

Быстрое развёртывание на Linux/macOS с Bash и Python 3.10+: скопируйте проект на машину, перейдите в его каталог и выполните:

```bash
./deploy.sh
./deploy.sh --launch
```

Первый вызов подготавливает `.venv` и зависимости, затем завершает работу. `--launch` выполняет ту же подготовку и запускает интерфейс; отдельная подготовка перед ним необязательна. Повторные вызовы переиспользуют окружение, а при изменении `requirements.txt` обновляют зависимости. Скрипт работает и при вызове по пути из другого каталога, включая пути с пробелами: `"/путь к проекту/deploy.sh" --launch`.

Параметры развёртывания:

| Команда | Действие |
|---|---|
| `./deploy.sh` | Подготовить окружение без запуска TUI |
| `./deploy.sh --launch` | Подготовить окружение и запустить TUI |
| `./deploy.sh --check` | Подготовить окружение и проверить WebDAV |
| `./deploy.sh --version` | Подготовить окружение и показать версию |
| `./deploy.sh --help` | Справка без установки |

Если файл скрипта при переносе потерял исполняемый бит, используйте `bash deploy.sh --launch`. Установка выполняется в каталоге проекта, без `sudo`; на первой установке нужен доступ к индексу пакетов. Если стандартный Python не содержит `venv`/`ensurepip`, установите соответствующий пакет для своей ОС либо используйте установленный `uv`. Скрипт не создаёт и не запрашивает credentials: после запуска введите их в панели «Доступ» и сохраните зашифрованно. Для `--check` действуют ограничения зашифрованного хранилища, описанные ниже.

Прямой запуск из интерактивного терминала также доступен:

```bash
./run.sh
```

Python 3.10+; Textual 7, Requests и cryptography. Зависимости изолированы в `.venv`. Если окружение отсутствует, launcher создаёт его через uv (если установлен) или стандартный venv и устанавливает `requirements.txt`. Для первой установки нужен доступ к индексу Python-пакетов; при запуске также проверяется изменение requirements.

Приложение не содержит абсолютных путей конкретной машины. При запуске через `run.sh` или `deploy.sh` загрузки по умолчанию идут в `downloads` внутри каталога проекта; при прямом запуске Python — внутри текущего рабочего каталога. Путь назначения можно изменить прямо в интерфейсе: поддерживаются абсолютные и относительные пути, пробелы и `~`.

Launcher рассчитан на Linux/macOS с Bash. На Windows используйте PowerShell и Python напрямую:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe cloudmail_downloader.py
```

Зашифрованное хранилище: `$XDG_CONFIG_HOME/cloudmailru/credentials.enc` на POSIX (по умолчанию `~/.config/cloudmailru/credentials.enc`), `%APPDATA%/cloudmailru/credentials.enc` на Windows (резервный путь — `~/AppData/Roaming`). Относительный XDG/APPDATA игнорируется. Уже существующий файл по старому пути `~/.config/cloudmailru/credentials.enc` имеет приоритет.

Логин и WebDAV ключ можно ввести прямо в интерфейсе. Все поля скрыты. Введите мастер-пароль (минимум 12 символов) и нажмите «Сохранить зашифрованно». Данные атомарно записываются в конфигурационный каталог: AES-256-GCM, ключ выводится из мастер-пароля через scrypt (N=32768, r=8, p=1), соль и nonce случайны при каждом сохранении. На POSIX файлу и каталогу назначаются режимы `0600` и `0700`; на Windows приложение не настраивает ACL, используются унаследованные права каталога пользователя. Мастер-пароль не записывается и после операции очищается из поля.

При следующем запуске введите мастер-пароль и нажмите «Расшифровать». Credentials доступны в памяти процесса; зашифрованный файл имеет приоритет над `.env` и переменными окружения. Неверный пароль и повреждение шифротекста отклоняются. Без зашифрованного файла сохраняется совместимость с `.env` и переменными окружения. Во время скачивания смена аккаунта запрещена. Облако используется только для чтения.

Старый `~/.config/cloudmailru/credentials.env` больше не читается и автоматически не удаляется. Для переноса заполните логин/ключ и сохраните зашифрованно, затем проверьте разблокировку. Старый файл и `.env` остаются незашифрованными копиями: удалите их самостоятельно, если они больше не нужны. Забытый мастер-пароль восстановить нельзя; можно заново ввести credentials и сохранить с новым паролем.

Основной экран оставляет каталог в центре. Путь назначения показывается одной редактируемой строкой над ним. Логин, WebDAV ключ и мастер-пароль находятся в компактной панели **«Доступ»**, которая не занимает рабочую область постоянно.

При выборе файлов под таблицей появляется сводка: количество файлов, общий размер и свободное место в папке назначения. Для выбранных папок размер считается рекурсивно в фоне с промежуточным числом найденных файлов и их объёмом. Если обход прервался, найденные значения остаются видны с пометкой «Подсчёт не завершён» и ошибкой. Запас места и ETA по выбору показываются после полного обхода; ETA требует замера фактической скорости скачивания. Неизвестные размеры отмечаются отдельно.

Прочитанные каталоги сохраняются в памяти текущего сеанса и используются для навигации, сводки и подготовки скачивания. Одновременные обращения к одной папке ожидают один общий запрос. После сбоя успешно прочитанные каталоги сохраняются: повторный запуск скачивания запрашивает только недостающие данные. Чтобы увидеть изменения в облаке, нажмите **«Обновить»** (`r`): эта команда сбрасывает весь кэш каталогов и пересчитывает выбор. Смена аккаунта и перезапуск приложения также очищают кэш.

При тайм-ауте, обрыве соединения или временном HTTP-ответе `429`, `500`, `502`, `503`, `504` запрос списка папки выполняется максимум три раза с тайм-аутами чтения 30, 60 и 120 секунд и паузами 1 и 2 секунды между попытками. Ошибки доступа `401`/`403` и отсутствие объекта `404` не повторяются автоматически. Во время подготовки загрузки остановка проверяется между объектами обхода; уже выполняющийся запрос с его повторными попытками должен завершиться.

Если отдельный файл не скачался, остальные файлы очереди продолжают загрузку. После завершения очереди с реальными ошибками открывается окно **«Ошибки загрузки»**: в нём видны путь, причина, сохранённый размер `.part`, текущий статус и подробности выбранной строки. Поиск и фильтры отделяют временные ошибки, требующие внимания, остановленные и скачанные файлы. Под общей подписью **«Повторить:»** расположены кнопки **«Текущий файл»**, **«Отмеченные (N)»** и **«Все временные»**. Последняя запускает только временные сетевые и HTTP-ошибки; отдельный файл можно повторить вручную после исправления причины. Строки отмечаются кликом, Пробелом или Enter. Успешно скачанный файл сразу исчезает из текущего списка; его можно увидеть через фильтр **«Скачанные»**.

Окна **«Ошибки загрузки»** и **«Докачка»** используют общий компонент списка и прогресса: полосу, процент, скорость, полученный и общий объём, число готовых файлов и ошибок. **«Пауза»** приостанавливает передачу, **«Продолжить»** возобновляет её, **«Стоп»** сохраняет частичные данные. После завершения с ошибками показывается **«Завершено с ошибками»**, а курсор переходит к файлу с ошибкой. Бережный повтор выполняется последовательно, с тайм-аутом чтения 90 секунд, максимум пятью попытками и паузами 5, 15, 30 и 60 секунд; частичный `.part` продолжается. Кнопка **«Стоп»** также прерывает ожидание между попытками. Штатная остановка исходной загрузки не считается ошибкой и не открывает окно ошибок. Ошибки доступа и другие постоянные ошибки не повторяются автоматически.

После успешного скачивания строка файла становится серой, а отметка выбора снимается. После перезапуска пометка восстанавливается при проверке той же папки назначения и аккаунта. Частичные, найденные на диске и требующие проверки файлы выделяются жёлтым, ошибки — красным. Подтверждённые готовые файлы пропускаются при повторной загрузке папки. Файлы с изменившейся версией в облаке или локальными данными требуют проверки; удалённые локальные файлы снова доступны для загрузки. Чтобы скачать ещё одну копию, выберите другую папку назначения. У полностью скачанной выбранной папки также снимается отметка выбора.

Сравнение с диском использует полный объём выбора, без вычитания существующих файлов и `.part`; это консервативная оценка. Для ещё не созданной папки проверяется диск ближайшего существующего родительского каталога. Время выбора оценивается по последней измеренной скорости текущего сеанса; в блоке активной загрузки показывается оставшееся время с учётом уже скачанных байтов. Это приблизительная оценка, зависящая от сети и сервера.

Управление:

| Действие | Клавиша |
|---|---|
| Перемещение | Стрелки |
| Открыть папку | Enter |
| Родительская папка | b |
| Выбрать файл/папку | Space |
| Обновить каталог / повторить соединение | r |
| Скачать выбранное | d или кнопка |
| Пауза / продолжить | p |
| Остановить с сохранением частичных файлов | x |
| Открыть путь в веб-интерфейсе | o |
| Выйти с остановкой потоков | q |

Кнопка **«Скачать»** — единственное основное действие. **«Доступ»** и **«Обновить»** остаются вторичными. Прогресс, скорость, общий объём и ошибки находятся в одном нижнем блоке. После сохранения или разблокировки credentials каталог загружается заново. Если credentials отсутствуют, приложение всё равно запускается и предлагает открыть панель «Доступ».

Tab переключает фокус между таблицей, папкой назначения, числом потоков (1–16) и кнопкой. Выбор сохраняется при переходах между каталогами. Выбранные папки скачиваются рекурсивно с сохранением структуры; вложенные повторные выборы исключаются. Общий размер вычисляется после сканирования, до загрузки. Скорость отражает реально полученные байты за последний интервал, отдельно учитывая ранее скачанные данные. Неизвестные размеры отмечаются явно.

Последняя папка назначения запоминается отдельно для каждого аккаунта. При следующем запуске приложение в фоне проверяет диск и версии файлов в облаке. Раздел **«Докачка»** показывает частичные, ещё не начатые и неудачные загрузки из сохранённой очереди. Нажмите **«Продолжить все»** или отметьте строки кликом, Пробелом или Enter и нажмите **«Отмеченные (N)»**. Скачивание само не начинается. **«Проверить»** повторяет сверку с облаком, **«Стоп»** сохраняет частичные данные. Проверка очереди работает после разблокировки аккаунта; недоступный или изменившийся источник требует проверки.

Очередь сохраняется в `.cloudmail-downloads.sqlite3` внутри папки назначения до передачи файлов, а готовые файлы отмечаются по ходу работы. Сохраните журнал вместе со скачанными файлами. Последние папки назначения записываются в `downloads-session.json` рядом с зашифрованным хранилищем credentials; паролей и ключей в нём нет. Старые `.part` с подходящими `.part.json` также обнаруживаются. Готовые файлы без журнала получают статус **«Найден на диске»**, когда их путь можно сопоставить с открытым каталогом облака. **«Принять файл»** явно подтверждает такой экземпляр: совпадение пути и размера само по себе не является проверкой содержимого. Частичные файлы без корректных метаданных не продолжаются автоматически.

Рядом с частичным файлом сохраняются `.part` и `.part.json` с версией исходного файла и идентификатором аккаунта. Возобновление использует `Range`/`If-Range`; поддерживаются ответы `Content-Range` как со стандартным `bytes start-end/total`, так и с `bytes=start-end/total`, встречающимся у Mail WebDAV. В обоих случаях проверяются границы и размер ответа. Если сервер игнорирует Range или нет валидатора версии, скачивание начинается заново. Полный `.part` повторно загружается с проверкой версии перед публикацией. Готовые файлы не перезаписываются; конфликты показываются как ошибки. Во время передачи файла пауза/остановка действует на границе блока; обычный тайм-аут чтения без данных — 30 секунд (это не предел длительности всей передачи), а для бережного повтора — 90 секунд. Папка назначения блокируется на время загрузки; служебный файл `.cloudmail-download.lock` остаётся на диске.

Частичные загрузки версий до 1.2.0 не содержат идентификатора аккаунта: автоматически продолжать их небезопасно. Переместите старые `.part` и `.part.json` либо выберите новую папку и скачайте заново. Существующие готовые файлы и зашифрованное хранилище совместимы с 1.2.0.

Имена, отличающиеся только регистром или нормализацией Unicode, и имена, совпадающие со служебными `.part`/`.part.json`, отклоняются в одной очереди на всех системах. Скачивайте такие объекты в разные папки назначения.

Дата создания показывается только из WebDAV `creationdate` и не интерпретируется как доказанная дата загрузки в облако. Дата изменения — `getlastmodified`; MIME тип — `getcontenttype` (или расширение). WebDAV не предоставляет подтверждённых публичных ссылок: `o` открывает частный путь в веб-интерфейсе Mail, где требуется авторизация; разрешение ссылки для конкретного файла зависит от интерфейса Mail.

## Официальная документация и проверка

[Официальная справка Mail: доступ по WebDAV](https://help.mail.ru/cloud/desktop/webdav/) подтверждает адрес `https://webdav.cloud.mail.ru/` и пароль внешнего приложения вместо основного пароля. Детальную документацию API Mail не публикует на этой странице; методы и свойства реализованы по [RFC 4918 (WebDAV)](https://www.rfc-editor.org/rfc/rfc4918) и [RFC 9110 (HTTP Range)](https://www.rfc-editor.org/rfc/rfc9110).

```bash
./run.sh --check
```

Если существует зашифрованное хранилище, используйте TUI для разблокировки и проверки подключения; `--check` мастер-пароль не запрашивает.

Версия 1.7.0 проверена на локальном HTTP-сервере и в Textual headless TUI: 92 теста, включая список из 23 425 файлов, восстановление очереди после перезапуска, сверку диска и облака, оба формата `Content-Range`, выделение строк, прогресс докачки, удаление успешно скачанных строк и переход к оставшимся ошибкам. Автоматические тесты не обращаются к личному облаку. Для проверки своего подключения используйте `--check` с данными из окружения/`.env` или разблокировку в TUI.

Проверки разработчика:

```bash
uv pip install --python .venv/bin/python pytest
.venv/bin/python -m pytest -q
.venv/bin/python -m py_compile cloudmail_downloader.py download_state.py conftest.py test_downloader.py test_download_recovery.py test_download_session.py
uv pip check --python .venv/bin/python
bash -n run.sh deploy.sh
```

Без uv зависимости тестов можно установить через `python -m pip install pytest` внутри виртуального окружения.

Перенос проверен на Linux в чистой копии проекта, без `.env`, прежнего виртуального окружения и пользовательских загрузок, в каталоге с пробелами. Нативные macOS и Windows в этом ревью не запускались; их поддержка требует проверки на целевой системе. Имена, запрещённые Windows (например, `NUL`, `file:stream`, завершающая точка), отклоняются с сообщением, а не преобразуются.

Публикация файла на POSIX требует hard-link, а блокировка — поддержки файловой системой. При отсутствии поддержки (например, FAT/exFAT на Linux/macOS) операция завершится ошибкой и сохранит `.part`. На Windows используется переименование без перезаписи. Работайте в своей папке назначения: блокировка координирует экземпляры приложения с одной и той же папкой, но не сторонние программы и не загрузки в пересекающиеся каталоги.

Результаты ревью и ограничения проверки: [REVIEW.md](REVIEW.md).
