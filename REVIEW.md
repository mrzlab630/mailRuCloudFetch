# Code review 1.2.0

Ревью выполнено 14.10.2026 по исходному коду, тестам и чистой копии проекта.

## Исправленные дефекты

- DAV href декодируется один раз и повторно кодируется только при построении URL; пути с `#`, `?`, `%` и `;` не теряют имя.
- Объекты принимаются только из успешных `207 Multi-Status` propstat и только как прямые дети запрошенного каталога.
- Возобновление связывается с путём, размером, валидатором версии, адресом WebDAV и пользователем аккаунта.
- Полный `.part` снова проходит HTTP-проверку версии; готовые файлы не перезаписываются.
- Публикация на POSIX использует hard-link, поэтому итоговый файл не появляется недописанным; при ошибке `.part` сохраняется.
- Папка назначения блокируется на время batch-загрузки; конфликт служебных имён и выход через локальные имена отклоняются.
- Коллизии регистра, Unicode и имён частичных файлов выявляются до начала скачивания, в том числе на системах без учёта регистра.
- Сканирование размера и проверка свободного места выполняются вне UI-потока; устаревший результат фонового сканирования не возвращает старый выбор.
- Навигация очищает старую таблицу до запроса нового каталога и проверяет пустой курсор.
- Конфигурация не содержит путей конкретной машины, проверяет типы зашифрованного JSON и не выводит credentials.

## Независимая проверка

Claude Opus (`claude-opus-5-5`, настроенный локальный провайдер) прочитал снимок исходников без доступа к инструментам и данным аккаунта. Первый отчёт содержал ложные срабатывания: command injection через `Path.expanduser()`, удаление `.part` после ошибки `os.link` и обход проверки symlink через `resolve()`. Они проверены по коду и регрессионным тестам, затем отозваны при повторном независимом ревью. Подтверждённый риск коллизий регистра/Unicode устранён.

Повторный вердикт по исправленному снимку: **APPROVED**, без воспроизводимых дефектов в заявленной области применения — персональный загрузчик с фиксированным HTTPS-сервером Mail в собственной папке пользователя. Это ревью исходников, не сертификация безопасности и не проверка реального аккаунта.

Нативные macOS и Windows не запускались в этой среде. Windows-ветки блокировки и публикации проверены только статически; недопустимые имена проверены параметризованными тестами. Приложение не настраивает Windows ACL. Перед заявлением подтверждённой поддержки нужен запуск на целевой ОС.
